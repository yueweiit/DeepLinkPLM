# 供应商范围采用与款式选样

本次沿用既有供应商范围、选品保存、权限、来源快照和审计。

- 目录编辑可明确采用供应商某个冻结版本的型号范围，仍需原保存操作；不自动组合颜色。
- 选样可先保存款式及原型号要求，具体型号后补；不把供应商全部可供型号自动当成已选型号。
- 拟拿样数量保留零、正数和未定的区别。保存不产生产品、实际收样或样品批次。
- 默认目录按既有款式身份及配置消除补图来源的重复显示；来源维护、历史和图片保留。
- 复用现有会话保持、取消编辑和重复提交保护。

验证：96个后端用例（含17个本地隔离PostgreSQL用例）、255个前端用例、类型检查与完整构建通过。另以完整Spring后端及普通Vue页面验证保存、取消、刷新、数量和范围版本。
