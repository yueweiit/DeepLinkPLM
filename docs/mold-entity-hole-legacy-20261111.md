# 新增共模映射：孔型及历史编码实施记录

## 已实现行为

- 表单增加孔型（大孔D、精孔J、混合H）、原模具编码、新规则编码预览；产品未选择时显示提示，不显示0。
- 已明确的孔型自动沿用；历史other由工程明确选择，保留原关系，新增明确孔型的制造关系。
- 最早原模具主码不变。历史九位完整码可作为实体主码；为所选旧机型补新规则映射码，为新增机型生成对应映射码，均关联原实物套。
- 已有同实体、机型、材质、孔型、结构的有效映射直接复用。不同实物、占用编码、失效版本及不一致孔型拒绝保存。
- 编码公式：M + 产品2位 + 材质2位 + D/J/H + 手机码4位，保留前导零。生成与解析复用ProductBusinessCodeGenerator。
- 原码、实物套数量、开模费用和各机型成品/SKU不改写。无需审批，工程确认保存生效。

## 修改文件及调用链

1. `plm-web/src/views/mold-sharing/MoldShareMappingView.vue`：表单、候选孔型过滤、分页读取全部候选、原码与预览展示、过期预览丢弃。
2. `plm-web/src/api/modules/moldSharing.ts`：新增预览方法，确认请求可选增加holeType，旧调用缺省沿用原关系孔型。
3. `plm-server/src/main/java/com/yuewei/plm/module/moldsharing/MoldShareMappingController.java`：新增POST `/api/v1/mold-share-mappings/entities/preview`。
4. `plm-server/src/main/java/com/yuewei/plm/module/moldsharing/MoldShareMappingService.java`：预览与确认共用校验/生成分支，历史源机型补映射、重复复用及同实物制造关系维护。

页面选择产品/孔型/已有机型/新增机型 → 预览接口 → 校验权限、主数据、关系版本和完整实物适配 → 统一生成器生成PC/TPU两组编码 → 页面展示 → 原确认接口 → 事务锁及重新校验 → 实体主码、源/目标映射、制造关系、审计。

预览不会生成数据库业务记录；采用普通事务以兼容现有主数据的FOR SHARE锁。确认事务失败全部回滚。本次无需数据库迁移。

## 手工验收业务流

1. 8111 → 基础资料 → 共模映射 → 新增共模映射。
2. 选择产品、孔型、已有共模机型；核对展示的PC/TPU原模具编码。
3. 选择新增适用机型，核对已有机型和新增机型的新规则编码预览。
4. 填写工程确认依据及原因，确认并生效。
5. 列表保留原模具主码，在共用编码中显示映射码，适用机型加入原组。
6. 再选该组任意机型加入另一机型，确认仍指向原实物套。重复保存不重复建码。

本次验证覆盖映射建立及制造身份解析，不代表已经执行真实生产工单、库存出入库或成本结算。
