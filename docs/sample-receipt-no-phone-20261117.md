# 通用样品：无需手机型号

收样表单每款增加「无需手机型号」复选框。工程人员明确勾选后，可按实际颜色、数量登记通用或非手机壳样品，不创建假手机型号。颜色和正整数数量仍为必填，库位继续选填。

## 复用与兼容

- 继续使用原收样预览/保存、供应商颜色、来源版本校验、SY/SP、数量流水和审计；没有新增接口、业务表或迁移。
- 请求字段为可选的 phoneModelApplicability: not_applicable。缺省仍执行现有手机型号规则，与正手机型号同时提交被拒绝。
- 无型号身份按真实款式、颜色和技术配置匹配；重复收样复用 SY，不与已有手机型号或未核实型号的历史样品合并。
- 仅收样时确认颜色的来源可标记；已确认具体型号/颜色组合的历史来源继续受原校验约束。质检、签名和放行维持原流程。
- 当前行与「本次跳过」中同款规格同步标记，保留颜色文字和数量；恢复不会丢标记。保存结果未知时继续重放原请求。
- 旧手机样品路径仍供现有所有手机壳选品、历史批次、二维码和其他客户端使用，不作迁移或删除。
