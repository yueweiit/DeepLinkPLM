# 基础资料已有模具组共模映射实现与验收报告

## 一、已实现效果

- 在「基础资料 → 共模映射」保留单表展示，字段为：模具编码、孔型、适用机型、共用的模具编码、状态。
- 「新增共模映射」候选改为直接读取「模具管理」已有模具组，不再要求先存在制造关系。
- 表单按产品、已有模具组、具体模具套、孔型、组内基准机型、新增适用机型、编码预览、工程确认依据、确认原因填写。
- 一组只有一套模具时自动选中；已有明确孔型时自动沿用；旧数据没有孔型时由工程人工选择。
- 组内有多个已有机型时任选一个作为基准；尚未登记机型的历史模具套允许人工选择实际已开模机型。
- 工程确认后直接生效，不调用钉钉审批，不新建实物模具套，不合并 SKU 或库存。
- 旧模具编码保留；缺少新规则主码时生成主码，同时为基准机型和新增机型生成映射码并指向同一实体模具。
- 多个机型若生成同一个映射码，允许按手机维度登记，但编码解析仍校验必须指向同一实体，避免一号多模。

## 二、编码规则

`M + 产品特定码 2 位 + 材质 2 位 + 孔型 1 位 + 手机码 4 位`

- 材质：TPU=`10`，PC=`20`
- 孔型：大孔=`D`，精孔=`J`，混合=`H`
- 历史完整九位码继续作为最早可追溯实体主码；无完整主码时，按基准机型生成首次主码。
- 同一实体模具可拥有多个手机映射码，生产流转按映射码解析到实体模具套。

## 三、调用链路

1. 页面选择产品，调用 `GET /api/v1/mold-share-mappings/existing-groups`。
2. 后端从 `plm_collaboration_item / mold_set / mold_part / phone_member` 读取模具管理主档。
3. 选择模具套、基准机型、孔型及新增机型，调用 `POST /existing-groups/preview`。
4. 预览校验产品、主档状态、PC/TPU 完整性、孔型、编码占用、实体冲突，并返回主码、基准映射码、新增映射码和 `sourceDigest`。
5. 工程填写依据和原因，调用 `POST /existing-groups/confirm`。
6. 确认事务内补正式码、部件编码关联、实体身份、手机成员、套适配、制造关系和实体映射。
7. 调用 `ManufacturingIdentityService.requireResolved` 验证生产身份可解析后，记录主档版本、协作历史和操作日志。

## 七、测试业务流

1. 登录本地系统 `http://127.0.0.1:8111`。
2. 进入「基础资料 → 共模映射」。
3. 点击「新增共模映射」。
4. 选择产品，系统加载模具管理已有模具组。
5. 选择已有模具组和具体模具套；单套时自动选中。
6. 选择孔型；历史套没有孔型时由工程人工确认。
7. 选择组内任一已有机型作为基准；没有已登记机型时人工选择实际已开模机型。
8. 选择新增适用机型，检查 PC/TPU 主码、基准映射码和新增映射码预览。
9. 填写工程确认依据和确认原因，点击「确认并生效」。
10. 返回单表检查适用机型和共用编码；再用生产流转的解析接口按映射码确认其落到同一 `itemId + moldSetId + entityId`。
