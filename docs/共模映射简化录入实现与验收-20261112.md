# 共模映射简化录入实现与验收

## 已实现

- 新增弹窗简化为：产品、已开模机型、新增适用机型、孔位类型、材质多选、工程确认依据、确认原因。
- 正常流程不再展示模具组、模具套和内部编号。
- 新增 `/api/v1/mold-share-mappings/auto-match/preview` 与 `/auto-match/confirm`，老接口保持不变。
- 自动匹配依次使用实体映射、制造关系、手机套适配、手机模具成员以及模具管理中的精确机型名称数据。
- 唯一匹配自动选中；无匹配提示补资料；多匹配时才显示实体模具选择。
- TPU、PC 支持单选或多选，只生成和确认本次选择的材质映射。
- 旧编码保留，新机型映射码继续指向同一实体模具。
